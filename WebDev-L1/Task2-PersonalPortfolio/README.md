# OIBSIP — Web Development Level 1, Task 2

Personal portfolio website for Ijeoma Godspower.

## Features
- Responsive navigation with smooth scrolling
- Hero section with a reserved profile-photo placeholder
- About, skills, projects, services and contact sections
- Featured work: SafeAttend, NaijaFoods and a separate React + TypeScript portfolio
- Email, LinkedIn and GitHub contact links
- Responsive layouts for desktop, tablet and mobile
- Lucide icons

## Tech stack
- HTML5 and CSS3
- Manrope headings and Sora body typography
- CSS Grid, Flexbox, gradients and responsive media queries
- Lucide icons
