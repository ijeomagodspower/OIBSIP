# OIBSIP — Web Development Level 1, Task 2
## Michael Jackson Tribute Page

A responsive editorial-style tribute page inspired by the supplied design reference.

### Design
- Background: `#111111`
- Accent: `#E31C25`
- Text: `#FFFFFF`
- Display typeface: Bodoni Moda
- Supporting typeface: Manrope
- Long-form magazine layout with a sticky navigation, oversized display type, image-led sections, timeline and quote.

### Features
- Hero with subject name and one-line tagline
- Four concise original biography paragraphs
- Career milestone timeline
- Distinct quote block
- Multiple image sections
- Responsive desktop and mobile layouts
- Smooth-scroll navigation
- Image credits and license links
