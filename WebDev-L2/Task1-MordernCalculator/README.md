# OIBSIP — Web Development Level 2, Task 1

A responsive browser calculator with a minimal mobile-inspired interface and light/dark themes.

## Features
- Digits 0–9 and decimal input
- Addition, subtraction, multiplication and division
- Operator precedence and chained calculations
- Clear all, backspace, sign toggle and percentage
- Division-by-zero error handling
- Light and dark theme switch
- Keyboard support
- Responsive CSS Grid keypad
- No inline event handlers and no JavaScript eval()

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript
- Roboto Flex and Roboto Mono

## Run locally
Open index.html in a modern browser.
